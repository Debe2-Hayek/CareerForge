# Homepage slider emblems

3D icons from [3dicons](https://3dicons.co) by Vijay Verma (github.com/realvjy/3Dicons), "clay" style,
released under **CC0 1.0** (free for commercial use, no attribution required; credited here anyway).
Resized to 320 px WebP. Files are named after the slide (`profile` = sheild, `checks` = tick,
`learning` = map-pin, `workshops` = medal, `cv` = file-text, `jobs` = travel, `tracker` = folder,
`assistant` = chat-text, `portfolio` = computer). They are tinted and lit in CSS (`src/app/slider.css`).
